Reasoning: A shape placed at random positions would make every pixel vary, and a fixed glyph would have connected strokes. Neither fits. What fits is a small, fixed collection of sparse random-looking binary patterns (dot constellations) on a black background. Pixels that are black in all of them become the dead W1 rows. The h2 units act as "which pattern is this" detectors, and each one's W3 row writes that pattern's scattered white pixels. Pixels that always appear together have identical W1 rows. Lines, blobs, digits and letters are ruled out because no unit's pixel set is spatially connected. So the sampler reproduces (memorises) one of these fixed dot patterns.

Images: A black 12 x 12 field with roughly 8-15 isolated white pixels, scattered and not connected. Each image is one of a small fixed set of such patterns. For example, one pattern has white pixels at (row, col) (0,7), (0,10), (1,0), (1,10), (4,2), (4,3), (5,4), (8,7) and (11,11). About a quarter of the grid is never lit, for example (0,2)-(0,5), (7,4), (7,5) and (11,10).
